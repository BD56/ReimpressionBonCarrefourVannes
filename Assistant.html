Mettre l'application en ligne

Google demande de faire cette étape vous-même. « Ouvrir la page de mise en ligne » ouvre la bonne page dans un nouvel onglet : suivez ces 7 gestes, puis revenez ici.

  1. En haut à droiteDéployer ▾
  2. Dans le menuNouveau déploiement
  3. Type (sinon : roue dentée ⚙️)Application Web
  4. Exécuter en tant que (déjà rempli)Moi
  5. Qui a accès (déjà rempli)Tout le monde
  6. En bas à droiteDéployer
  7. Sous « URL de l'application Web »Copier

Google peut redemander les autorisations : faites comme au premier clic. Ne choisissez pas « Utilisateur accédant à l'application Web » : chaque poste aurait besoin d'un compte Google.

Les postes du magasin

Chaque poste qui imprime des bons ouvre ce lien. Aucun compte Google n'est nécessaire sur les postes.

  1. Ouvrez le lien sur un posteOuvrir ↗
  2. Vérifiez le nom du magasin en haut de la page
  3. Imprimez une page de bons et passez un code-barres en caisse
  4. Ajoutez le lien aux favoris de chaque poste☆ Favori

Le lien n'est pas protégé par un mot de passe : transmettez-le seulement aux postes du magasin.

✓

L'application est installée

L'onglet « Application » du Google Sheets rappelle le magasin et le lien. Pour changer le nom ou l'adresse : menu 🚀 APPLICATION → Assistant d'installation.
